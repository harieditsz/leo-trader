# Trading Tools

Static HTML tools (no build step):

- `nifty50-checklist.html` – Nifty 50 entry checklist
- `xauusd-checklist.html` – XAUUSD setup checklist
- `atr-day-range-calculator.html` – ATR day range calculator

## Host on GitHub Pages
1. Create a new repo and upload all files in this folder to the root of the `main` branch.
2. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`.
3. Site will be live at `https://<username>.github.io/<repo>/`
